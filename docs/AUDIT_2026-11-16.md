# Audit de securitate și plan de produs — 16 noiembrie 2026

Punct de plecare: `8e2b615`, ramura `main`, arbore de lucru curat.
Acest raport completează auditurile istorice; nu certifică absența tuturor
vulnerabilităților. Constatările din cod, observațiile live și propunerile sunt
separate. Nu include date de utilizatori, secrete sau adresele originii.

## Concluzie și limite

Produsul are deja peste 25 de operații PDF, API, SDK, procesare asincronă,
partajare, RO/EN, MFA, passkeys și o infrastructură de observabilitate.
O rescriere sau adăugarea nediferențiată de unelte ar crește riscul și mentenanța.
Prioritatea este repararea autentificării, protejarea datelor și îmbunătățirea
fluxurilor existente, cu modificări mici și verificabile.

Inspecția live este numai de citire: containere, vhost-ul acestui proiect,
antete HTTPS și versiuni instalate. Testele folosesc o copie a fișierelor
versionate, imaginea aplicației și PostgreSQL/pgvector temporar, pe o rețea
Docker separată. Nu se folosesc `.env`, baza de date, Redis, bucket-ul sau
documentele de producție. Nu se execută teste de încărcare pe domeniul public.

## Dovezi inițiale

- Două replici web și nginx intern raportează stare sănătoasă. Web și worker
  folosesc `runsc-net`; rădăcina containerului web este numai pentru citire.
- Traseul observat este Cloudflare → nginx de pe host → nginx Docker → Django.
  Existența unui proces cloudflared pe VPS nu demonstrează că acest domeniu
  folosește un tunnel; configurația providerului nu a fost verificată acum.
- HTTPS răspunde cu HSTS, CSP cu nonce, nosniff și protecție împotriva încadrării.
  Cloudflare raportează `DYNAMIC` pentru paginile verificate. Nu s-a demonstrat
  o scurgere prin cache; lipsesc totuși antete explicite pentru unele pagini
  sensibile și descărcările API.
- Versiuni observate în imaginea activă: Python 3.12.15, Django 5.2.17,
  DRF 3.18.3, PyMuPDF 1.28.0, cryptography 50.0.0, Pillow 13.0.0,
  requests 2.34.2, urllib3 2.8.0, webauthn 3.0.1.
- Mediul `venv/` de pe host este nefuncțional: interpreterul este Python 3.14,
  iar Django nu este disponibil. Verificările se execută separat în containere.
- Vhost-ul activ diferă de `infra/nginx/pdf_editor.conf`: lipsesc ruta SSE
  dedicată și politica de cache pentru resurse statice. Aceasta este derivă
  operațională, nu o vulnerabilitate demonstrată de acces la documente.

## Plan de implementare

1. **Autentificare:** reproduce N01/N02 în mediul izolat, repară și verifică
   autentificarea web/admin, MFA și passkeys. Commit separat.
2. **Confidențialitate și factori:** N03/N04, apoi N06 dacă testele permit o
   modificare mică, fără migrare. Commit separat pentru fiecare etapă coerentă.
3. **Produs și responsive:** N08, păstrând limbajul vizual existent; validare la
   320, 390, 768 și 1440 px, tastatură, RO/EN și stări fără rezultate.
4. **Încheiere:** suita completă, lint, scanare statică și audit de dependențe;
   consemnarea exactă a rezultatelor și limitărilor. SEO și CI se verifică aici,
   după funcționalitate, fără extinderi artificiale ale pipeline-ului existent.

Fiecare etapă are commit fără atribuiri sau trailere de coautorat, folosind
identitatea existentă în istoricul proiectului. Commitul local nu înlocuiește
imaginea care rulează. Publicarea se face separat, după verificări, prin fluxul
de build/deploy existent; nu implică modificarea altor proiecte de pe VPS.

## Evaluare CISO a schimbărilor propuse

- **Amenințări prioritare:** ocolirea MFA (spoofing/elevation), expunerea
  documentelor/secrețelor (information disclosure), epuizarea resurselor prin
  parsare/joburi (DoS). Impact ridicat; probabilitatea nu este cuantificată.
- **Rază de impact:** compromiterea unui staff privilegiat poate expune
  documentele și datele de cont accesibile aplicației. Nu au fost citite date de
  utilizatori pentru a inventa un număr de persoane sau o estimare financiară.
- **Detecție:** există Prometheus/Grafana și request IDs; nu s-a verificat acum
  livrarea alertelor către o persoană și nici timpul real de detecție.
- **Răspuns:** există `docs/RUNBOOK.md` și `docs/DR.md`; un exercițiu incident/
  restaurare nu a fost executat în această etapă. Acesta rămâne un criteriu de
  pregătire operațională, nu un rezultat dedus din existența documentelor.
- **Date și furnizori:** nu se adaugă furnizori și nu se schimbă retenția.
  Cloudflare/R2, SMTP și AI extern trebuie incluse în inventarul de procesatori;
  contractele și obligațiile legale nu au fost verificate în acest audit tehnic.
- **Verdict:** corecțiile pot fi implementate și testate local; lansarea cere
  verificarea suitei, compatibilității și rollbackului. Riscurile rămase sunt
  urmărite explicit, fără declararea produsului drept complet securizat.
